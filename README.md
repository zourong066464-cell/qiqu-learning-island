# 奇趣学习岛

面向小学 1–3 年级的中文趣味学习网页应用，支持手机、平板和电脑。

## 玩法

- 口算森林：一年级 20 以内加减，二年级 100 以内加减及表内乘法，三年级加减、乘法和整除。
- 汉字花园：字词、拼音、量词、古诗和基础表达选择题。
- 英语云朵：36 个常见英语词汇，按年级分组。
- 记忆星球：6 组中英文翻牌配对。
- 其他功能：错题复习、星星徽章、学习记录、备份与恢复。

题库为基础练习示例，不覆盖完整教材。支持游客本机记录，以及可选的家长邮箱账号、个人昵称和跨设备同步。云端连接信息尚未配置，当前线上仍是游客模式。

## 使用

手机：打开 GitHub Pages 网址，在 iPhone Safari 中使用共享 → 添加到主屏幕；Android Chrome 中使用安装应用或添加到主屏幕。首次联网加载并成功缓存后，支持的浏览器可离线使用。

电脑：下载本仓库，解压后用浏览器打开 index.html 即可使用。无需安装依赖。请保留完整文件夹；账号界面使用同目录的 JavaScript 文件。

本仓库使用 GitHub Pages 从 main 分支根目录发布，不需要额外构建。

## 验证

已通过 JavaScript 语法与核心逻辑校验，包括 9,000 道随机口算抽查、重复提交防护、错题重做、记忆配对及备份校验。手机实机显示、主屏幕安装与离线缓存仍需在目标设备验证。

## 账号与同步

已实现邮箱注册/验证、登录/退出、重置密码、独立昵称与进度、离线暂存、同步状态及版本冲突选择。每个家长邮箱对应一个孩子档案。

启用步骤见 [ACCOUNT_SETUP.md](ACCOUNT_SETUP.md)。需要项目所有者创建 Supabase 项目、执行迁移、配置邮箱服务并填写公开连接信息；仅更新 GitHub 无法提供数据库。没有连接时仍可游客使用，游客记录不会自动并入新账号。

验证：`node --test tests/cloud.test.cjs` 测试账号切换、网络中断、同步竞争和会话刷新；`node tests/game.test.cjs` 测试原有答题与备份逻辑。账号测试使用模拟接口，不能替代真实服务验收。数据库行级权限测试见 `supabase/tests/isolation.sql`，尚待在真实测试项目运行。
